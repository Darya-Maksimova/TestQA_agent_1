# Мультиагентная QA-система на базе OpenCode

Проект представляет собой интеллектуальную мультиагентную систему, разработанную для автоматизации ключевых задач QA-специалиста: от анализа требований до создания задач на разработку и проектирования тест-кейсов.

## Архитектура системы

В основе системы лежит паттерн «Оркестратор — Субагенты». Взаимодействие построено на базе скиллов (Skills):

1. **QA Orchestrator** (`AGENTS.md`) — центральный управляющий агент. Отвечает за маршрутизацию задач между субагентами, контроль контекста и прохождение Quality Gates.
2. **Requirement Reviewer** (`skills/requirement-review`) — анализирует исходные требования из Confluence, выявляет противоречия, пробелы и формирует структурированный артефакт.
3. **Task Designer** (`skills/task-design`) — декомпозирует проанализированные требования и создает готовые к работе задачи в Jira (с Acceptance Criteria).
4. **Test Designer** (`skills/test-design`) — проектирует тестовую модель (позитивные, негативные и граничные сценарии) на основе требований и создает тест-кейсы в TMS.

## Интеграции

Взаимодействие с внешними системами реализовано следующим образом:
*   **Confluence** — через кастомный инструмент `tools/confluence.ts` (использует REST API v2 для надежного чтения страниц).
*   **Jira** — через локальный MCP-сервер (`jira-local`).
*   **Testomat.io** — через локальный MCP-сервер (`testomat`).
