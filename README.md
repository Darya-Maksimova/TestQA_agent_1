# Мультиагентная QA-система на OpenCode

Домашнее задание: реализация мультиагентной системы для автоматизации работы QA-специалиста.

## Архитектура агентов
Система состоит из главного Оркестратора и трех специализированных агентов (Skills):
1. **QA Orchestrator** (`AGENTS.md`) — управляет процессом, вызывает агентов и проверяет Quality Gates.
2. **Requirement Reviewer** (`skills/requirement-review`) — анализирует требования из Confluence.
3. **Task Designer** (`skills/task-design`) — декомпозирует требования и создает задачи в Jira.
4. **Test Designer** (`skills/test-design`) — создает тест-кейсы (позитивные/негативные) в Testomat.

*Примечание: В задании упоминалась система Qase, но в рамках данной реализации было принято решение использовать **Testomat.io**, так как для него успешно настроен MCP-сервер.*

## Интеграции
*   **Confluence** — через кастомный инструмент `tools/confluence.ts` (использует REST API v2).
*   **Jira** — через локальный MCP-сервер (`jira-local`).
*   **Testomat.io** — через локальный MCP-сервер (`testomat`).

## ⚙️ Настройка окружения
Для работы системы в системе (Windows) должны быть заданы следующие переменные окружения:
*   `CONFLUENCE_URL` = `https://maksimovadascha.atlassian.net`
*   `CONFLUENCE_EMAIL` = ваш email от Atlassian
*   `CONFLUENCE_API_TOKEN` = ваш API-токен Atlassian
*   `CLOUDRU_API_KEY` = ключ для доступа к LLM (DeepSeek)

Конфигурация MCP-серверов находится в файле `opencode.json`.

## 🚀 Как запустить
1. Убедитесь, что все MCP-серверы работают (в терминале выполните `opencode mcp list`, все должны быть `connected`).
2. Запустите OpenCode.
3. Отправьте в чат следующий промпт:

> Используй инструмент confluence, чтобы прочитать страницу 1376257 (Требования к ЗЯ). На основе этих требований:
> 1. Сформируй 3 задачи для разработки и создай их в Jira (проект [УКАЖИТЕ_КЛЮЧ_ПРОЕКТА]).
> 2. Сгенерируй тест-кейсы (позитивные и негативные) и добавь их в Testomat (в проект testcafe-demo-project-30ad2).

## Результаты работы
После завершения работы агентов, итоговый отчет сохраняется в файл `artifacts/final_report.md`.
Скриншоты созданных задач и тест-кейсов находятся в папке `artifacts/`.
